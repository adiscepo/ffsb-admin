In the other domains (Docu, Events, etc.), I use Actions as a way to store one single action, while it's good when the model doesn't need a lot of interaction, it can expand in a lot of files when the number of action increase.

In the context of kanban, there are a LOT of actions available between creating new boards/columns/tasks, moving and reordering them. So I'll be using a new way of grouping them known as _Services Classes_.
